# Jejak Kinerja AI — Tickets (MVP)

Artefak tiket yang dihasilkan dari **PRD** (`docs/PRD-JEJAK-KINERJA-AI.md`) dan **Spec** (`.scratch/jejak-kinerja-ai-mvp/spec.md`).

## Isi

- `jejak-kinerja-ai-tickets.csv` — Siap tempel ke **GitHub Issues/Jira** (kolom: `Epic, Key/Judul, Tipe, Prioritas, Deskripsi, AC, Referensi PRD`).
- File Markdown di folder ini — Konten tiket terperinci (untuk copy/paste atau impor manual).

## Catatan

- Status spec: `ready-for-agent` (lihat spec). Issue tracker eksternal belum dikonfigurasi di repo (lihat *Further Notes* di spec).
- Bahasa: konten tiket dalam **Bahasa Indonesia** (sesuai aplikasi). Identifikasi teknis dalam Bahasa Inggris bila perlu.
- Prioritas: **P1** = MVP inti, **P2** = penting/pendukung MVP, **P3** = SHOULD/out-of-scope MVP (ditandai jelas).
- User stories di spec bernomor 1–100; referensi PRD mengacu ke bagian modul/section terkait di `docs/PRD-JEJAK-KINERJA-AI.md`.
